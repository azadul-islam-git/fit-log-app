# FitLog

FitLog is a workout and exercise management web application where users can explore exercises, view detailed workout information, create their daily workout plan, and save exercises for later.

## 🚀 Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- daisyUI
- React Hot Toast
- React Icons

## ✨ Key Features

1. **Explore Exercises**
   - Browse a collection of exercises with information such as muscle groups, equipment, difficulty, duration, calories, and rating.

2. **Exercise Details**
   - View detailed information about each exercise, including description, instructions, equipment, sets, reps, and other workout statistics.

3. **Today's Workout Plan**
   - Add exercises to your daily workout plan and easily view all exercises you've selected for the day.

4. **Save Exercises for Later**
   - Save exercises that you want to revisit later without adding them directly to today's workout plan.

5. **Duplicate Prevention & Toast Notifications**
   - Prevent duplicate exercises from being added to your plan or saved list and provide instant feedback using toast notifications.
